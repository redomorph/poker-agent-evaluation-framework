# Project Documentation

The documentation is divided by purpose:

- `specs/` — binding scientific and technical project specification;
- `decisions/` — architectural/scientific decision records explaining why a versioned choice was made;
- `reports/` — generated or manually written experiment and validation reports.

Start with [`specs/README.md`](specs/README.md).

The root `README.md` remains the project entry point for installation, status, architecture overview, and links into the detailed specification.
